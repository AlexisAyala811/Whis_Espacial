# Créditos de las texturas de interiores

Las siguientes texturas se mezclan con materiales generados por el proyecto. Son de Poly Haven, bajo [CC0](https://polyhaven.com/license), y se han descargado en 1K:

- [Metal Plate](https://polyhaven.com/a/metal_plate), Rob Tuytel.
- [Rubber Tiles](https://polyhaven.com/a/rubber_tiles), Amal Kumar.
- [Dirty Carpet](https://polyhaven.com/a/dirty_carpet), Rohit Seervi.
- [Floor Tiles 02](https://polyhaven.com/a/floor_tiles_02), Rob Tuytel.
- [Concrete Floor Painted](https://polyhaven.com/a/concrete_floor_painted), Rob Tuytel.
- [Painted Plaster Wall](https://polyhaven.com/a/painted_plaster_wall), Amal Kumar.

Si no se carga una fotografía se mantiene la textura procedural. El recurso gráfico de Wali se generó para este proyecto a partir de una imagen aportada por el usuario; es un personaje de interfaz ficticio.
